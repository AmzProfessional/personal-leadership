## Що таке персональне лідерство?
- [x] Здатність керувати собою, своїми реакціями та розвитком
- [ ] Здатність контролювати роботу підлеглих
- [ ] Формальна керівна посада в компанії
> Персональне лідерство починається з управління собою, а не іншими.

## Оберіть складові персонального лідерства
type: multiple
- [x] Самосвідомість
- [x] Саморегуляція
- [x] Проактивність
- [ ] Мікроменеджмент
> Перші три — базові складові моделі. Мікроменеджмент їй прямо суперечить.

## Керівник помічає, що команда систематично не встигає в терміни.
Які дії будуть доречними в першу чергу?
- [x] Переглянути обсяг завдань і пріоритети разом із командою
- [ ] Ввести штрафи за зрив дедлайнів
- [ ] Збільшити кількість статус-зустрічей
> Спершу перевіряють навантаження й пріоритети, а не посилюють контроль.
